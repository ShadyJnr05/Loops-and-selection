Python: Loops & Selection

Rules that cost marks

Python groups statements by indentation. Keywords are lowercase: if, else, while, for. Every condition line ends with a colon. Use == to compare and = to assign.

Selection: if / else

num = int(input("Enter a number: "))
if num > 0:
    print("Positive number")
else:
    print("Negative number")

int() converts input to an integer. input() always returns text, so convert it before doing maths.

While loop: unknown number of repeats

count = 1
while count <= 5:
    print(count)
    count = count + 1

Three parts: start the counter, test the condition, change the counter. Forget the last one and the loop never ends.

total = 0
count = 1
while count <= 5:
    total = total + count
    count = count + 1
print(total)   # 15

Check your notes: the sum example uses number in the condition but count in the body. Use one name.

For loop: known number of repeats

for i in range(start, stop, step):
    statement

start is the first value, the loop ends before stop, and step is how much it changes each time.

for count in range(3, 6):      # 3, 4, 5
for i in range(5):             # 0 to 4 (5 times)
for count in range(2, 12, 2):  # 2, 4, 6, 8, 10
for x in range(3, 8, 2):       # 3, 5, 7

Accumulating a total

Set sum = 0 before the loop for addition. For multiplication start at 1.

total = 0
for i in range(1, 10, 2):   # odd numbers 1 to 9
    total += i
    print(i)
print(total)                # 25

Commands

print()displays output
input()receives user input
int()converts to integer
float()converts to decimal
str()converts to string
range()generates a sequence of numbers
